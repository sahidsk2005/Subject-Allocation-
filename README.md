# 🎓 Subject Allocation System (Python)

A Python-based **Subject Allocation System** designed to simplify and automate the process of allocating subjects to students. This project helps manage student details, subject selection, and allocation records efficiently.

---

## 📌 About the Project

The Subject Allocation System is an academic project developed using Python. It aims to reduce manual work and make the subject allocation process faster, easier, and more organized.

The system allows users to manage student information and allocate available subjects according to the defined allocation rules.

## 🎯 Project Objectives

- Automate the subject allocation process.
- Manage student information efficiently.
- Simplify subject selection and assignment.
- Reduce manual errors.
- Save time and improve accuracy.
- Maintain organized allocation records.

## ⚙️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main Programming Language |
| Lists | Store student and subject data |
| Dictionaries | Manage allocation information |
| Functions | Organize program operations |
| Loops | Process student records |
| Conditional Statements | Apply allocation rules |

## 💻 Installation and Execution

**Step 1: Clone the repository**

```bash

```

**Step 2: Open the project folder**

```bash
cd Subject-Allocation-System
```

**Step 3: Run the Python program**

```bash
python subject_allocation.py
```
